## 8. FIX BEFORE-AND-AFTER IMAGE ALIGNMENT

The existing cladding comparison has a noticeable alignment problem.

The original and visualised images do not line up accurately.

This must be fixed properly.

### Image preparation requirements

- Use the original photograph as the fixed geometric reference.
- Preserve camera angle and perspective.
- Preserve wall dimensions.
- Preserve window positions and sizes.
- Preserve rooflines and structural features.
- Preserve the original photograph's framing.
- Do not independently regenerate the entire building image.
- Align matching permanent reference points.
- Correct perspective or cropping differences before comparison.
- Export both images at identical pixel dimensions.
- Ensure identical aspect ratios.

If creating a modified version, alter only the intended finish or relevant visual area.

### Slider implementation requirements

- Both images must occupy exactly the same container.
- Both images must use identical dimensions and positioning.
- Use one shared image coordinate system.
- Reveal the upper image using CSS clipping or masking.
- Do not independently move either image.
- Use a vertical draggable comparison handle.
- Start at 50%.
- Support mouse and touch.
- Support keyboard interaction.
- Prevent unwanted page scrolling during horizontal dragging.
- Avoid image stretching.
- Avoid layout shifts.
- Maintain alignment at every screen width.
- Use accessible labels.

### Important fallback

If the images cannot be aligned accurately, do not display a broken comparison.

Replace the slider with a static image layout until a correctly matched pair is available.

A clean static photograph is better than an inaccurate interactive comparison.
