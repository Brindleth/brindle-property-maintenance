# Design inspiration assets

Generated with the built-in image_gen tool for the owner's requested refinement. These are fictional illustrative examples, not completed Brindle projects. No stock photographs, API key, paid production integration or generation service is used by the website.

The selected PNG masters are preserved locally in `references/inspiration-generated/` (Git-ignored). Published responsive WebPs are in `public/images/inspiration/`; each image has 480, 960 and 1440 pixel variants. Run `npm.cmd run assets:inspiration` with the local masters present to regenerate. A fresh clone builds using committed derivatives.

Images were visually inspected for photorealistic materials, plausible residential scale, clean architectural composition, absence of branding and suitability for the requested capabilities. The section displays an explicit AI disclosure and every image carries an inspiration label. None enters the genuine-project stage data.
